# 🎂 Kitty’s Birthday Experience — The Weeknd Inspired

Uma landing page interativa criada para servir como convite digital de aniversário com inspiração visual no universo do The Weeknd.
O projeto foi pensado exclusivamente para **mobile**, trazendo uma experiência moderna, imersiva e diferente dos convites tradicionais.

A proposta mistura:

* UI/UX moderna
* efeitos neon
* estética dark/light mode
* interações com JavaScript
* formulário dinâmico
* experiência visual cinematográfica

---
